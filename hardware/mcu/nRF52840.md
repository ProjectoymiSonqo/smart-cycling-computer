# Nordic nRF52840

## Purpose

The nRF52840 serves as the main processing unit of the Smart Cycling Computer.

It coordinates sensor acquisition, wireless communication, navigation, user interface, and system management.

---

## Why nRF52840?

Selected because it provides:

- Integrated BLE 5
- Native ANT+ support
- Low-power operation
- Sufficient Flash and RAM for embedded applications
- Mature Nordic SDK and development ecosystem

The goal is to build a portable cycling computer without requiring an external wireless MCU.

---

## Responsibilities

The MCU is responsible for:

- GNSS data acquisition
- NMEA parsing
- BLE communication with mobile application
- ANT+ communication with heart-rate and power sensors
- Display update
- Sensor management
- Airspeed calculation
- Battery monitoring
- Power management

---

| Peripheral | Interface |

| MPU6500 | I2C |
| MAX17048 | I2C |
