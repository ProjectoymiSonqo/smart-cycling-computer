# ILI9486 TFT Display

## Purpose

Provides graphical user interface for navigation and riding information.

---

## Why Selected?

Selected because:

- Large display area
- Mature driver ecosystem
- SPI interface
- Suitable resolution for cycling computer

---

## Interfaces

SPI

Resolution

320 × 480

---

## Responsibilities

- Navigation display
- Riding information
- System status
- User interaction
