# ILI9486 TFT Display

## Purpose

Provides graphical user interface for navigation and riding information.

---

## Why Selected?

Selected because:

- Large display area
- Mature driver ecosystem
- SPI interface
- Suitable resolution for cycling computer

---

## Interfaces

SPI

Resolution

320 × 480

---

## Responsibilities

- Navigation display
- Riding information
- System status
- User interaction

---
## Pin Assignment

| ILI9486 Pin | nRF52840 GPIO | Notes |

|-------------|---------------|-------|

| VCC | 3.3V | Power |

| GND | GND | Ground |

| SCK | P0.31 | SPI Clock |

| SDI (MOSI) | P0.30 | SPI MOSI |

| CS | P0.28 | SPI Chip Select |

| DC / RS | P0.04 | Command / Data Select |

| RESET | P0.29 | Hardware Reset |

| LED | P0.03 | Backlight Enable |

| SDO (MISO) | Not Connected | Readback not required |

| T_CLK | Not Connected | Touch controller |

| T_CS | Not Connected | Touch controller |

| T_DIN | Not Connected | Touch controller |

| T_DO | Not Connected | Touch controller |

| T_IRQ | Not Connected | Touch controller |

---


## Design Notes

Current prototype only supports LCD display.

Touch controller is intentionally left unconnected.

ILI9486 write-only SPI mode is sufficient for the current implementation, so the MISO line is not connected.

The backlight is controlled by GPIO (P0.03) to allow future brightness control using PWM.
