# Smart Cycling Computer

An open embedded cycling computer designed to quantify real-world riding performance.

## Motivation

After completing a cycling tour around Taiwan, I wanted to better understand how aerodynamic drag affects riding performance.

Most cycling computers provide speed and navigation, but very few measure relative airspeed or estimate CdA.

This project explores a modular cycling computer capable of integrating GNSS, BLE and Pitot tube based airspeed sensing.


## Features

- Modular hardware architecture
- GNSS navigation
- BLE connectivity
- ANT+ sensor support
- Relative airspeed measurement
- CdA estimation
- Front light expansion interface
